# AI 对话

openAIDE的 AI 对话是核心交互方式，支持流式输出、工具调用、@文件引用等高级功能。

## 打开 Chat Panel

- **快捷键**：`Cmd/Ctrl+L`
- **命令面板**：`OpenAIDE: Open Chat`
- **侧边栏**：点击 AI 图标

## 基本对话

在输入框中输入问题，按 `Enter` 发送。AI 会以流式方式逐字输出回复。

```
你：帮我写一个 React 登录组件，要求支持邮箱和手机号登录

AI：好的，我来为你创建一个登录组件...
    [调用 file-write 工具创建文件]
    [显示代码 + Diff 预览]
```

## @文件引用

在消息中使用 `@` 引用项目文件，AI 会自动读取文件内容作为上下文：

```
@src/utils/auth.ts 这个文件的 validateToken 函数有 bug，帮我修复
```

支持的引用方式：
- `@文件路径` — 引用单个文件
- `@目录/` — 引用目录下所有文件
- `@*.ts` — 引用匹配模式的文件

## 工具调用

AI 在回复过程中可能会调用内置工具（如读写文件、执行命令等）。工具调用会显示在对话中：

```
🔧 调用工具: file-read
   参数: { path: "src/App.tsx" }
   ✅ 成功读取 (245 行)

🔧 调用工具: file-edit
   参数: { path: "src/App.tsx", ... }
   ⏳ 等待审批...
   [接受] [拒绝]
```

### 工具审批

- **低风险工具**（读取文件、搜索）：自动执行
- **中风险工具**（写入文件）：首次需要确认
- **高风险工具**（执行命令）：每次需要确认

详见 [权限管理](/guide/permissions)。

## 会话管理

### 新建会话

- 快捷键：`Cmd/Ctrl+Shift+N`
- 命令：`OpenAIDE: New Chat`

### 会话历史

- 命令：`OpenAIDE: Chat History`
- 支持搜索、删除、导出

### 会话标题

AI 会自动为每个会话生成标题，也可以手动修改。

## 上下文管理

### 自动上下文

openAIDE会自动收集以下上下文信息：
- 当前打开的文件
- 光标所在位置
- 项目 `.openaide.md` 配置
- 相关的记忆条目

### 上下文压缩

当对话过长时，openAIDE会自动压缩上下文：
1. 保留最近的消息
2. 压缩早期消息为摘要
3. 保留关键的工具调用结果

详见 [上下文压缩](/guide/context-compact)。

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Cmd/Ctrl+L` | 打开/聚焦 Chat |
| `Cmd/Ctrl+Shift+N` | 新建会话 |
| `Enter` | 发送消息 |
| `Shift+Enter` | 换行 |
| `Cmd/Ctrl+Shift+C` | 复制最后回复 |
| `Escape` | 取消当前请求 |
