# 记忆系统

openAIDE的记忆系统让 AI 能够跨会话保持上下文，记住你的偏好、项目规范和历史决策。

## 三层记忆架构

```
┌─────────────────────────────────┐
│         会话记忆 (Session)        │  当前对话中自动提取
├─────────────────────────────────┤
│         项目记忆 (Project)        │  .openaide.md + 项目级记忆
├─────────────────────────────────┤
│         全局记忆 (Global)         │  ~/.openaide/memory/
└─────────────────────────────────┘
```

### 会话记忆

- 在当前对话中自动提取的临时记忆
- 会话结束后可选择保存为项目/全局记忆
- 包括：用户偏好、临时指令、上下文信息

### 项目记忆

- 存储在项目目录的 `.openaide.md` 文件中
- 包括：项目说明、代码规范、技术栈、架构决策
- 所有在该项目中的对话都会自动加载

### 全局记忆

- 存储在 `~/.openaide/memory/` 目录
- 跨项目生效的长期记忆
- 包括：编码风格偏好、常用工具配置、个人习惯

## 记忆分类

openAIDE支持 8 种记忆分类：

| 分类 | 说明 | 示例 |
|------|------|------|
| `preference` | 用户偏好 | "使用 2 空格缩进" |
| `codeStyle` | 代码风格 | "函数使用箭头函数" |
| `architecture` | 架构决策 | "使用 Repository 模式" |
| `bugfix` | Bug 修复记录 | "注意 null 检查" |
| `knowledge` | 领域知识 | "API 限流 100 次/分钟" |
| `workflow` | 工作流程 | "提交前运行 lint" |
| `context` | 上下文信息 | "项目使用 pnpm" |
| `other` | 其他 | 未分类的记忆 |

## 自动记忆提取

AI 在对话过程中会自动识别值得记住的信息：

```
你：以后写组件都用函数式组件，不要用 class 组件
AI：好的，我记住了。[自动保存为 codeStyle 记忆]

你：这个项目的 API 基础 URL 是 https://api.example.com/v2
AI：了解。[自动保存为 context 记忆]
```

## 记忆管理面板

通过侧边栏的记忆图标打开管理面板：

- 📋 按分类浏览所有记忆
- 🔍 搜索记忆内容
- ✏️ 编辑记忆条目
- 🗑️ 删除不需要的记忆
- 📤 导出/导入记忆

### 命令

- `OpenAIDE: Memory Manager` — 打开管理面板
- `OpenAIDE: Add Memory` — 手动添加记忆
- `OpenAIDE: Search Memory` — 搜索记忆

## 云同步

记忆支持通过云同步服务在多台设备间同步，详见 [云同步](/guide/cloud-sync)。
