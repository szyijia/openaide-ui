## 为什么选择openAIDE？

openAIDE是一款**深度集成 AI Agent 能力的桌面 IDE**，不同于插件形态的 AI 编程助手，openAIDE将 AI 能力融入 IDE 的每一个角落。

### 与其他工具的对比

| 特性 | Cursor | Continue | Cline | **openAIDE** |
|------|--------|----------|-------|----------|
| 形态 | 闭源 IDE | VS Code 插件 | VS Code 插件 | **开源定制 IDE** |
| Agent 能力 | 有 | 有限 | 有 | **完整（40+ 工具）** |
| Multi-Agent | 无 | 无 | 无 | **有（Team 模式）** |
| MCP 协议 | 有限 | 有 | 有 | **完整实现** |
| 上下文压缩 | 有 | 基础 | 基础 | **高级（9 步压缩）** |
| 记忆系统 | 无 | 无 | 无 | **自动记忆提取** |
| 多模型 | Claude/GPT | 多模型 | 多模型 | **多模型 + 智能路由** |
